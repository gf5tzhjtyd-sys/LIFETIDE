LIFETIDE 개인정보 처리방침

시행일: 2026년 8월 27일

LIFETIDE(이하 “앱”)는 사용자의 경조사 기록을 개인적으로 관리하기 위한 앱입니다. 이 처리방침은 앱이 기록을 저장하고 동기화하는 방식을 설명합니다.

1. 앱이 다루는 정보

  • 사람의 이름, 관계, 소속, 메모, 즐겨찾기 정보
  • 경조사 종류, 날짜, 보냄·받음 구분, 금액, 메모, 태그
  • 사용자가 만든 관계·경조사 종류·태그 분류
  • 사용자가 직접 생성한 백업 파일

2. 저장 및 iCloud 동기화

기록은 우선 사용자의 기기에 저장됩니다. iCloud 동기화를 사용할 수 있는 환경에서는 사용자의 Apple 계정에 연결된 개인 iCloud 데이터베이스로 동기화될 수 있습니다.

LIFETIDE 개발자는 사용자의 개인 iCloud 기록에 접근하거나 이를 열람하지 않습니다. 앱에는 광고, 행동 분석, 외부 로그인, 제3자 추적 SDK가 포함되어 있지 않습니다.

3. 백업 및 파일 가져오기

사용자가 선택한 경우 CSV·Excel 파일을 가져오거나, 전체 백업 파일을 내보내고 복원할 수 있습니다. 가져오기와 복원 전에 생성되는 자동 백업은 사용자의 기기에 최근 5개까지 저장됩니다.

파일을 공유하거나 외부로 저장하는 동작은 사용자가 iOS 공유 시트 또는 파일 선택 화면에서 직접 선택한 경우에만 수행됩니다.

4. 생체 인증

앱 잠금을 켠 경우 앱은 기기의 Face ID 또는 Touch ID를 사용해 잠금 해제를 요청할 수 있습니다. 생체 정보는 기기의 보안 영역에서 처리되며 LIFETIDE가 수집하거나 저장하지 않습니다.

5. 알림

사용자가 경조사 알림을 설정한 경우, 앱은 사용자의 기기에서 해당 시점에 로컬 알림을 표시할 수 있습니다.

6. 정보의 삭제와 관리

사용자는 앱에서 사람과 기록을 수정하거나 삭제할 수 있습니다. 기기 및 iCloud에 저장된 데이터 관리, iCloud 동기화 설정, 백업 파일 삭제는 사용자가 직접 제어할 수 있습니다.

7. 처리방침 변경

앱의 기능 또는 데이터 처리 방식이 변경되는 경우 이 처리방침을 업데이트할 수 있습니다.
